# Product Roadmap

## Vision

**Become the AI companion people trust whenever they want to give a meaningful gift.**

The roadmap focuses on validating the core value proposition first, then progressively expanding personalization and commerce capabilities.

---

# Phase 1 — MVP

## Goal

Validate whether **emotion-first recommendations** help users choose meaningful gifts with greater confidence than traditional product-first discovery.

### Features

* Guided conversational onboarding
* Recipient profiling
* Relationship understanding
* Occasion capture
* AI-generated gift recommendations
* Explainable recommendation rationale

### Success Metrics

* Recommendation completion rate
* Recommendation acceptance rate
* Average time to recommendation
* User satisfaction score

---

# Phase 2 — Personalization

## Goal

Reduce repeated effort and improve recommendation quality by learning from previous gifting experiences.

### Features

* Saved recipient profiles
* Gift history
* Favorite recommendations
* Occasion reminders
* Smart occasion detection
* Personalized recommendation refinement

### Success Metrics

* Repeat user rate
* Recommendation reuse rate
* Monthly Active Users (MAU)
* Recipient profile completion rate

---

# Phase 3 — Commerce

## Goal

Enable users to seamlessly purchase recommended gifts without compromising the product's emotion-first experience.

### Features

* Shopping platform integrations
* Price comparison
* Affiliate partnerships
* Wishlist creation
* Collaborative gifting
* Gift reservations

### Success Metrics

* Recommendation-to-purchase conversion rate
* Affiliate revenue
* Cart completion rate
* Average order value (AOV)

---

# Product Strategy

The roadmap intentionally follows a staged approach:

### Phase 1: Validate

Determine whether emotional context leads to higher-quality gift recommendations and greater user confidence.

### Phase 2: Personalize

Leverage user history and recipient profiles to improve recommendation relevance while reducing effort for repeat users.

### Phase 3: Monetize

Introduce commerce capabilities only after validating strong user engagement and recommendation quality, ensuring monetization enhances rather than detracts from the core product experience.
